# 🎮 Tic Tac Toe Game

A simple and interactive **Tic Tac Toe** game built using **HTML, CSS, and JavaScript**.

## 🚀 Live Demo

👉 **[Play Tic Tac Toe](https://tic-tac-toe-game-sable-five.vercel.app/)**

## ✨ Features

* 🎮 Two-player gameplay
* ❌ Player X and ⭕ Player O
* 🏆 Detects the winner
* 🔄 Restart game option
* 📱 Simple and responsive design

## 🛠️ Technologies Used

* HTML
* CSS
* JavaScript

## 📂 Project Structure

```text
tic-tac-toe/
│
├── index.html
├── style.css
└── script.js
```

## 🎯 How to Play

1. Player O starts the game.
2. Players take turns selecting an empty cell.
3. The first player to get three symbols in a row wins.
4. Restart the game to play again.

Made with ❤️ using HTML, CSS & JavaScript.
